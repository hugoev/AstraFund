Project Requirements Document: AstraFundThe Non-Profit Grant Compliance Co-Pilot1. Vision & Core PitchProject: AstraFundPitch: AstraFund is a collaborative financial management platform for non-profit organizations. It helps teams manage restricted grants by using an AI Co-Pilot (powered by the Gemini API) to automatically check expense requests for compliance before they are sent to a human for final, collaborative approval.Mission: We help non-profits "reach for the stars" (their mission) by "wrangling" the wild west of grant compliance.2. Target Hackathon TracksBest Overall: Technically advanced (full-stack + AI), solves a real problem, and has a polished design.Swivel Challenge:Community: Serves non-profit organizations.Move Money: Manages and tracks grant-specific funds in "secure wallets."Collaboration: Requires a "co-signing" workflow where a Program Manager requests and a Finance Director approves funds.Best Design: A clean, professional, and trustworthy UX/UI that makes a complex workflow feel simple and secure.Best Space Cowboy Theme: Branded as "AstraFund" (stars) and "wrangling" (cowboy) compliance.3. Core Personas (For Demo)Finance Director (Admin): "Sarah." She is responsible for compliance. She creates the "Grant Wallets" and has the final "co-sign" authority to approve or deny expenses.Program Manager (Member): "David." He is on the ground, running programs. He needs to spend money to get things done and submits expense requests.4. Data Models (SQLite Database)This simple schema is all you need for the MVP.Table: UsersDescriptionidINTEGER PRIMARY KEYnameTEXT (e.g., "Sarah - Admin", "David - Manager")roleTEXT ('admin' or 'manager')Table: GrantsDescriptionidINTEGER PRIMARY KEYnameTEXT (e.g., "Youth STEM Education Fund")total_amountREAL (e.g., 10000.00)spent_amountREAL (e.g., 750.00)rules_textTEXT (The full, long text of the grant's restrictions)Table: ExpensesDescriptionidINTEGER PRIMARY KEYgrant_idINTEGER (Foreign Key to Grants.id)user_idINTEGER (Foreign Key to Users.id - who submitted it)titleTEXT (e.g., "10x Raspberry Pi 4 Kits")amountREAL (e.g., 750.00)justificationTEXT (The manager's reasoning for the purchase)statusTEXT ('pending', 'approved', 'denied')ai_is_compliantBOOLEAN (The result from Gemini)ai_reasoningTEXT (The 1-sentence justification from Gemini)created_atTIMESTAMP (When it was submitted)5. Backend (Python/FastAPI or Node/Express)API Endpoints (RESTful)POST /login (Mock):Body: {"role": "admin"} or {"role": "manager"}Response: The mock User object.GET /grants:Response: Returns a list of all Grant objects with their total_amount and spent_amount.POST /grants (Admin Only):Body: {"name": "...", "total_amount": 10000, "rules_text": "..."}Action: Creates a new Grant in the database.POST /expenses (Manager Only):Body: {"grant_id": 1, "title": "...", "amount": 750, "justification": "..."}Action: This is the key.Saves the expense to the DB with status = 'pending'.Asynchronously (do not block) calls the AIService.check_compliance() function.The AI service updates the expense row with the ai_is_compliant and ai_reasoning fields.GET /expenses/pending (Admin Only):Response: List of all Expense objects where status == 'pending', joined with User (who submitted) and Grant (which fund).POST /expenses/:id/approve (Admin Only):Action: Calls SwivelService.execute_payment(). On success, updates Expense.status = 'approved'.POST /expenses/:id/deny (Admin Only):Action: Updates Expense.status = 'denied'.AI Service (AIService.py)Function: check_compliance(rules_text, expense_details)Gemini API System Prompt:"You are an expert grant compliance officer. Your job is to determine if a specific expense request complies with a set of grant rules. Analyze the rules and the expense. Respond only with a valid JSON object in the format: {\"is_compliant\": boolean, \"reasoning\": \"A brief, one-sentence justification for your decision.\"}"Gemini API User Prompt (Example):JSON{
  "grant_rules": "Funds must be used exclusively for purchasing technology and supplies for STEM education workshops targeting students aged 12-18. Funds cannot be used for food, travel, or administrative salaries.",
  "expense_request": {
    "title": "10x Raspberry Pi 4 Kits",
    "justification": "Purchasing these kits for our upcoming 'Intro to Robotics' workshop for high school students."
  }
}
Expected Gemini Response (to be parsed by your backend):JSON{
  "is_compliant": true,
  "reasoning": "This expense aligns with the 'purchasing technology for STEM education workshops' clause."
}
